# Weekly cadence

- **Monday:** create `weekly/<this-monday>.md`. Pick 1–2 shippable items per relevant hat. Tie each to a metric or open question in `VENTURE.md`.
- **Friday:** in the same file, log what shipped + what was learned. Update relevant hat docs and `VENTURE.md`.

Files are named by the Monday of the week (`YYYY-MM-DD.md`).

If a Friday review is skipped, note it at the top of the next Monday's file.
