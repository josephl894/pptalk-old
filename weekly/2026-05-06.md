# Week of 2026-05-06

## Goal of the week
**Hi-Fi design lands end-to-end.** Wave 1 ports the Hi-Fi design bundle into the home + new-project + sidebar shell; Wave 2 restyles the editor + render modal + voice library overlay; Wave 3 adds the Outline overlay, "Draft all narrations" bulk action, and the empty-script default for new uploads.

The bar: a friend can drop a deck, see empty narrations triaged in the Outline, draft them in one click, edit if needed, and render — without leaving the locked design system.

## What shipped (Mon-Tue)

### Engineering
- **Wave 1** — ported Hi-Fi tokens (paper / ink / accent / status / shadow ramps) into `globals.css` + `tailwind.config.ts`. Built `components/shell/` (Sidebar, AppShell, SlideThumb, StatusTag, ProgressRing, icons, StubPage). Added `(shell)` route group with sidebar layout; moved home into the group; built `/new` full-page upload + `/videos`, `/voices`, `/trash` stubs. Cmd-K palette retargeted to `/new`.
- **Wave 2** — restyled `EditorShell` to the 52px Hi-Fi top chrome + 168px filmstrip + center column + 296px right rail (Voice card / Slide settings card / Render card). Trimmed `ExportModal` to the 560px Loom shape with two locked toggles (Captions SRT + Quality 720/1080), preview card at top, render-complete checkmark intact as the one delight moment. Replaced the popover voice picker with `VoiceLibraryOverlay` (1080×720 Dialog, 6 voices grouped by tone, no language/accent/gender facets, default Alloy).
- **Wave 3** — added the **Outline overlay** (icon button in editor topbar) showing every slide row-wise; **"Draft all narrations"** bulk action wired to a new `POST /api/projects/[id]/draft-all` route that fans out N `slide_script_regen` jobs in one transaction; per-row "Draft this" sparkle in the overlay; "Draft this slide" hint inline in `ScriptCard` when empty + unlocked; reverted `/api/projects` to the flat-array contract; verified that `parse_only` already produces empty scripts for slides without notes (no pipeline change needed).
- **Six hotfixes** — Postgres pool exhaustion under HMR (`globalThis.__pptalk_pg` singleton + pool config), UUID validation at the route boundary, `NEXT_PUBLIC_*` env inlining, SceneRail SSR hydration via `next/dynamic` ssr:false, ExportModal helper hoisting, editor outer-grid `1fr → minmax(0, 1fr)` so the slide stays bounded by the viewport instead of pushing past it. All captured in `hats/engineering.md` "Patterns and pitfalls."

- Empty narrations are now obvious. Slides without speaker notes start blank; the Outline surfaces every empty row at a glance; "Draft all narrations" handles the bulk in a single click.
- Editor is on-brand top-to-bottom: Hi-Fi tokens, restrained chrome, the one designated delight moment preserved.
- Home + sidebar shell match the locked direction (Linear structure + warm coral).
